fit a common board well. Companion duck stays inside an encounter disc so it
is distinguishable from the full-body die-cut player duck.

The Seed shown on the sheet is a newly rendered family reference. The exact
[approved Seed asset](../2026-09-11-v3/seed-tile-v3.png) remains unchanged and is
still the production reference.

## Scope and inspection

Generated with the built-in image_gen tool. The complete prompt set and input
references are in [prompts.json](prompts.json). [inspection.json](inspection.json)
records native source paths, dimensions, hashes and review findings.

Both outputs are 1536 × 1024 PNGs, copied without editing or resampling. Root
inspected the rendered images: four complete tokens per sheet, seven new
categories plus the Seed reference, readable labels and representative strength 1
badges, distinct colours/shapes, and no cropped tokens.

These are opaque concept sheets, not isolated sprites or an alpha atlas.
Strength1 is illustrative; production strength numerals must be separate exact
overlays. Actual iPad readability and common physical sizing still need checking.
No approved artwork was replaced; no Unity calls/imports or game-code changes
were made. The later style approval is recorded at the top of this document.
