# M3 layout proof

**M3 is complete and ready for review.** `DuckLayoutProof` is the fixed-data
scene for the approved iPad layout. It
keeps the playable baseline separate and has no live match or Core binding.
The Editor entry points are **Quackies → Build Duck Layout Proof**, **Build and
Play Duck Layout Proof**, and **Write Duck Layout Audit**.

The proof covers all 50 fixed reward rows, eight haven links, the endpoint oasis
(`21 Sleep / 9 Twigs / 2 Feathers`), 11 Dream offers, Adventure/Dream navigation,
and 16 encounter-fit crops. The fixed board uses the native 1536 × 1024 board;
the production 3072 × 2048 master remains deferred until geometry review.

Review the native 1133 × 744 [Adventure](adventure.png), [occupied board](occupied.png),
[Dream](dream.png), [oasis inspection](oasis-inspection.png) and
[offer inspection](offer-inspection.png) captures. The [validation record](validation.md)
includes two stable rebuilds, target-size checks, actual button interactions
and a final Console query with zero errors.

M3 is visual layout evidence only. It does not change Core/CLI or live gameplay,
and it is not iOS export or device evidence. M4 waits for the user's next command.
